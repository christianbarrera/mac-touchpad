Set up secure connection

One time per phone. The touchpad then runs over HTTPS, so nobody else on this Wi-Fi can read what you type.

This Home Screen icon is the old, insecure version. Follow the steps below in Safari, add the new secure icon, then delete this one.
  1. Download the certificate profile

    Safari asks to allow a configuration profile: tap Allow, then Close.

    Download profile

    Not an iPhone? Get the plain certificate.

  2. Install it

    Settings → Profile Downloaded (near the top) → Install. It says “Not Verified”; that's expected for a certificate your own Mac made.

  3. Turn on full trust

    Settings → General → About → scroll to the bottom → Certificate Trust Settings → turn on Mac Touchpad Local CA.

  4. Open the secure touchpad

    Checking…

    Open secure touchpad

    Then Share → Add to Home Screen, open the new icon, and approve this phone on the Mac.

Check before trusting: in the profile's certificate details, the SHA-256 fingerprint must match the one the Mac prints at startup:

{{fingerprint}}

The certificate only works for .local names and private network addresses, so it can't be used to impersonate real websites.
